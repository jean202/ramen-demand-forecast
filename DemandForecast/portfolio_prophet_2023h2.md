# 라면류 수요예측 포트폴리오 정리

## 프로젝트 한 줄 소개

KT AIVLE 리테일 데이터 페스타의 원본 거래데이터를 활용해 `면류.라면류` 월별 판매수량을 Prophet으로 예측하고, `2023년 하반기`를 holdout 구간으로 분리해 성능을 검증했다.

## 왜 2023년 하반기 holdout을 썼는가

원래 목표는 `2024년 실제값`으로 holdout 검증을 하는 것이었다.
하지만 월별 실제값은 내부 데이터 기준 `2023년 12월`까지만 존재했고, 외부 공공자료인 FIS는 `라면류 월별`이 아니라 `면류(냉장) 반기별` 자료만 제공했다.
그래서 모델 검증은 가장 최근 실제 구간인 `2023년 7월~12월`을 시험지처럼 따로 떼어내는 방식으로 진행했다.

쉽게 말하면:
`2021~2023 상반기`로 공부시키고, `2023 하반기`를 정답 가린 시험지로 사용한 것이다.

## 데이터와 검증 설계

- 예측 대상: `면류.라면류` 월별 판매수량
- 전체 관측치: `2021-01 ~ 2023-12`, 총 `36개월`
- 학습 구간: `2021-01 ~ 2023-06`, 총 `30개월`
- holdout 구간: `2023-07 ~ 2023-12`, 총 `6개월`
- 최종 예측 구간: `2024-01 ~ 2026-12`

## 모델링 방법

비교한 모델은 세 가지다.

1. `기본 Prophet`
2. `전년동월 기준선`
   작년 같은 달 값을 그대로 가져오는 아주 단순한 모델
3. `튜닝 Prophet`
   holdout 성능 기준으로 Prophet 파라미터를 조정한 모델

선택된 최종 설정은 아래와 같다.

- `changepoint_prior_scale = 0.5`
- `seasonality_prior_scale = 0.1`
- `seasonality_mode = additive`

## 정량 성과

| 모델 | RMSE | MAE | MAPE |
| --- | ---: | ---: | ---: |
| 튜닝 Prophet | 1,176.02 | 899.11 | 11.27% |
| 전년동월 기준선 | 1,395.49 | 1,028.67 | 13.03% |
| 기본 Prophet | 2,765.79 | 2,163.38 | 28.16% |

### 비포/애프터

- `기본 Prophet -> 튜닝 Prophet`
  - MAPE `28.16% -> 11.27%`
  - MAPE 기준 `16.89%p` 개선
  - 상대 개선율 `59.98%`
  - RMSE 기준 `1,589.77` 감소

- `전년동월 기준선 -> 튜닝 Prophet`
  - MAPE `13.03% -> 11.27%`
  - MAPE 기준 `1.76%p` 개선
  - 상대 개선율 `13.51%`
  - RMSE 기준 `219.47` 감소

즉, 단순히 Prophet을 쓴 것이 아니라 `튜닝을 통해 기본 모델보다 훨씬 나아졌고`, 단순 기준선보다도 좋은 성능을 만들었다.

## holdout 결과 해석

`2023년 하반기` 실제값과 튜닝 Prophet 예측값은 아래와 같다.

| 월 | 실제값 | 튜닝 Prophet |
| --- | ---: | ---: |
| 2023-07 | 7,198 | 7,086.52 |
| 2023-08 | 7,880 | 6,864.82 |
| 2023-09 | 7,564 | 6,094.19 |
| 2023-10 | 8,505 | 6,298.68 |
| 2023-11 | 7,566 | 8,022.76 |
| 2023-12 | 7,647 | 7,782.10 |

해석 포인트는 이렇다.

- `7월`, `11월`, `12월`은 실제값에 비교적 가깝게 맞췄다.
- `10월`처럼 갑자기 튀는 구간은 다소 과소예측했다.
- 그래도 전체 오차 평균은 `MAPE 11.27%`로 관리 가능한 수준까지 줄였다.

## 2025~2026 미래 예측

최종 모델은 전체 실제 데이터(`2021-01 ~ 2023-12`)로 다시 학습한 뒤 `2024~2026`을 예측했다.
그중 포트폴리오에서 강조할 핵심은 `2025~2026`이다.

### 연간 예측 합계

| 연도 | 예측 판매수량 합계 |
| --- | ---: |
| 2025년 | 103,322.84 |
| 2026년 | 111,736.89 |

### 해석

- 2025년 대비 2026년 예측 합계는 증가 흐름이다.
- 월별 예측값을 보면 `11월`, `12월` 쪽이 상대적으로 높아 연말 강세가 나타난다.
- 즉 이 모델은 라면류 수요가 완만하게 증가하면서도 `하반기, 특히 연말로 갈수록 강해지는 계절성`을 가진다고 본다.

## 포트폴리오에 바로 붙일 수 있는 문장

### 짧은 버전

원본 거래데이터를 월별 시계열로 집계해 Prophet 기반 라면류 수요예측 모델을 구축했다.
월별 실제값이 존재하는 가장 최근 구간인 `2023년 하반기`를 holdout으로 분리해 검증한 결과, 튜닝 Prophet은 `MAPE 11.27%`, `RMSE 1,176.02`를 기록했다.
이는 기본 Prophet 대비 `MAPE 16.89%p` 개선된 수치이며, 전년동월 기준선보다도 더 낮은 오차다.

### 중간 버전

이번 프로젝트에서는 한국 라면류 판매 데이터를 월별 시계열로 재구성한 뒤 Prophet 모델을 적용해 수요를 예측했다.
외부 공공데이터(FIS)는 월별 라면류 데이터가 없어 검증용으로 사용하지 못했기 때문에, 내부 실제값이 남아 있는 가장 최근 구간인 `2023년 7월~12월`을 holdout으로 설정했다.
그 결과 기본 Prophet의 `MAPE 28.16%`를 `11.27%`까지 낮췄고, 전년동월 기준선(`13.03%`)보다도 더 좋은 성능을 확인했다.
최종 모델은 전체 데이터를 다시 학습한 뒤 `2025년 103,322.84`, `2026년 111,736.89` 수준의 연간 판매수량을 예측했다.

### 긴 버전

이 프로젝트에서는 KT AIVLE 리테일 데이터 페스타의 원본 거래데이터를 활용해 `면류.라면류` 월별 판매수량 예측 모델을 구축했다.
MongoDB 집계로 월별 시계열을 만들고 Prophet을 적용했으며, 단순 적용에 그치지 않고 holdout 검증 기반으로 파라미터를 튜닝했다.
원래는 `2024년 실제값`을 holdout으로 검증할 계획이었지만, 월별 실제값은 `2023년 12월`까지만 존재했고 FIS 공공자료는 `라면류 월별`이 아닌 `면류(냉장) 반기별` 자료만 제공되어 모델 검증용으로 사용하기 어려웠다.
이에 따라 가장 최근 실제 구간인 `2023년 하반기`를 holdout으로 설정했다.
검증 결과 튜닝 Prophet은 `MAPE 11.27%`, `RMSE 1,176.02`를 기록했고, 이는 기본 Prophet(`MAPE 28.16%`)보다 크게 개선된 결과다.
또한 전년동월 기준선(`MAPE 13.03%`)보다도 낮은 오차를 보여, 단순 계절 반복보다 더 나은 예측력을 확보했다.
최종 모델은 전체 실제 데이터로 재학습한 뒤 `2025년 103,322.84`, `2026년 111,736.89` 수준의 연간 판매수량을 예측했다.

## 발표할 때 쓰기 좋은 한 문장

`기본 Prophet을 그대로 쓰면 오차가 컸지만, 최근 6개월 holdout 검증으로 파라미터를 조정해 MAPE를 28.16%에서 11.27%까지 낮췄습니다.`

## 한계와 정직한 설명

- `2024 holdout`이 아니라 `2023 하반기 holdout`이다.
- 이유는 `2024 월별 실제값`이 없기 때문이다.
- FIS 자료는 `월별 라면류`가 아니라 `반기별 면류(냉장)`이어서 시장 참고자료로만 사용했다.
- 따라서 이 결과는 `현재 확보 가능한 데이터 범위 안에서 가장 최근 구간을 검증한 모델`이라고 설명하는 것이 가장 정확하다.
